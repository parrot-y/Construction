## Product fixes verified by this run

The first full run on this branch exposed two real App-routing bugs
(fixed in 2a5f28a, specs untouched):

1. `aud-stage2` test 8 — after a client portal link was revoked and the
   page reloaded, the token-redacted URL dropped to the landing page.
   Fix: active portal context persists in sessionStorage; reload now
   re-renders the portal and the revoked link shows the honest
   "expired or been switched off" state.
2. `g-contractor-journey` test 2 — revisiting `/?invite=<token>` while
   signed in rendered the workspace instead of the invitation state.
   Fix: `?invite=` takes precedence over an existing session; on
   successful acceptance the token is cleared from state and URL.

Both were reproduced failing, fixed, and re-verified green on both
viewports before this full run.
